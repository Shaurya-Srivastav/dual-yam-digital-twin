# Research notes

- **Touch-only localisation.** A particle belief over object pose updated from contact / no-contact measurements, with the next probe chosen by expected information gain: [Memory Unscented Particle Filter](https://doi.org/10.1109/tro.2017.2707092) ([arXiv:1607.02757](https://arxiv.org/abs/1607.02757)), [information-gain criteria for active tactile selection](https://ar5iv.labs.arxiv.org/html/2205.04697) ([arXiv:2205.04697](https://arxiv.org/abs/2205.04697), under 1 cm after 15 touches), [touch-only global localisation, ICRA 2026](https://doi.org/10.1109/icra57385.2026.11697596). Level 5 keeps the hard-likelihood (set-membership) fit of that belief. The next peck is the candidate that splits the centres still consistent with the touches so far about in half — a geometric information-gain rule, not a particle filter, and not an expected-entropy computation over a full pose belief.
- **Sensing a handle without moving it.** Set the contact threshold above sensor noise but below the breakaway force, pause on first contact, then estimate the joint from the contact pose: [Underactuated Robotic Hand with Grasp State Estimation Using Tendon-Based Proprioception](https://arxiv.org/abs/2509.12969) (Lee, Park, Cho; the contact-pause grasp), [Revisiting Proprioceptive Sensing for Articulated Object Manipulation](https://tlips.be/revisiting-proprioception-for-articulated-manipulation/) (Lips and wyffels), [Contact State Estimation using Machine Learning](https://kormushev.com/papers/Jamali_OCEANS-2013.pdf) (Jamali, Kormushev, Caldwell, OCEANS 2013; [DOI](https://doi.org/10.23919/oceans.2013.6740992)). Level 4 stops at ~0.9 N against ~1.5 N of swivel friction. That threshold is not the hidden-Markov contact classifier in the OCEANS paper.
- **Flipping a cup with one arm.** Lift clear, rotate with full poses (orientation-only goals can drive the cup into the table), and use the wrist roll. The in-hand alternative is [In-Hand Gravitational Pivoting Using Tactile Sensing](https://arxiv.org/abs/2210.05068) (Toskov et al., CoRL 2022; [HTML](https://ar5iv.labs.arxiv.org/html/2210.05068)). The roll attitude here was found by inverse-kinematics search. The wrist is turned to that attitude before the fingers close. Gravitational pivoting is not what runs: it depends on slip inside the fingers.
