# Research notes

- **Touch-only localisation.** A particle belief over object pose updated from contact / no-contact measurements, with the next probe chosen by expected information gain: [Memory Unscented Particle Filter](https://doi.org/10.1109/tro.2017.2707092) ([arXiv:1607.02757](https://arxiv.org/abs/1607.02757)), [information-gain criteria for active tactile selection](https://ar5iv.labs.arxiv.org/html/2205.04697) ([arXiv:2205.04697](https://arxiv.org/abs/2205.04697), under 1 cm after 15 touches), [touch-only global localisation, ICRA 2026](https://doi.org/10.1109/icra57385.2026.11697596). [Tac2Pose](https://doi.org/10.1177/02783649231196925) (Bauza, Bronars, Rodriguez, IJRR 2023; [arXiv:2204.11701](https://arxiv.org/abs/2204.11701)) pairs a grid of object poses with the contact each pose would make. Level 5 keeps a grid of cup centres and deletes the ones a flat pad footprint cannot explain. Both grippers lay the black pads flat. The cup arm stomps +y and the tap arm stomps −y. It is not a particle filter, it does not compute expected entropy, and it does not use the Tac2Pose embedding.
- **Sensing a handle without moving it.** Set the contact threshold above sensor noise but below the breakaway force, pause on first contact, then estimate the joint from the contact pose: [Underactuated Robotic Hand with Grasp State Estimation Using Tendon-Based Proprioception](https://arxiv.org/abs/2509.12969) (Lee, Park, Cho; the contact-pause grasp), [Revisiting Proprioceptive Sensing for Articulated Object Manipulation](https://tlips.be/revisiting-proprioception-for-articulated-manipulation/) (Lips and wyffels), [Contact State Estimation using Machine Learning](https://kormushev.com/papers/Jamali_OCEANS-2013.pdf) (Jamali, Kormushev, Caldwell, OCEANS 2013; [DOI](https://doi.org/10.23919/oceans.2013.6740992)). Level 4 reads the jaw width. A stall at 15 mm, the paddle width, is a square pinch and is turned to the pour angle. A narrower stall only says the paddle was touched. A short push is meant to walk that handle into the pour sector. There is no fingertip sweep and no learned classifier. That 24-trial has not been rerun on this search.
